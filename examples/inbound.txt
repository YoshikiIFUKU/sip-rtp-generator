# コールセンターへの着信を想定した通話原稿
# agent    = 電話機側 (local) = オペレーター
# customer = サーバ側 (remote) = お客様
# 設定は examples/config.json を参照

agent: お電話ありがとうございます。サポートセンターの山田でございます。
customer: あの、先月から料金プランのことで確認したいことがありまして。

agent: ご契約内容の確認ですね。恐れ入りますが、お客様のお電話番号をお願いいたします。
customer: はい、ゼロ、サン、イチ、ニ、サン、ヨン、ゴ、ロク、ナナ、ハチです。

# 相づちが被る場面。@wait に負の値を書くと直前の発話に重なる
@wait -0.6
agent: はい。

agent: ありがとうございます。ただいまお調べいたしますので、少々お待ちください。

# ここから保留。オペレーター側が re-INVITE (a=sendonly) を送る
@hold
@wait 6
@unhold

agent: 大変お待たせいたしました。ご契約は現在スタンダードプランとなっております。
customer: そうですか。それを一つ下のプランに変更することはできますか。
agent: はい、可能でございます。変更のお手続きを進めてもよろしいでしょうか。
customer: お願いします。

# 本人確認のため暗証番号を押してもらう (RFC 2833 の DTMF)
agent: それでは、四桁の暗証番号をダイヤルボタンで入力してください。
@dtmf customer: 1234#

agent: 確認できました。来月一日から新しいプランに変更となります。
customer: わかりました。ありがとうございました。
agent: お電話ありがとうございました。失礼いたします。

# オペレーター側から切断する
@hangup agent
