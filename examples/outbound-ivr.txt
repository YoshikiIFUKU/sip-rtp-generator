# 内線からの発信 → IVR 応答 → オペレーター転送、を想定した原稿
# agent = 電話機側 (local) = 内線 1001 からかけている人
# ivr   = サーバ側 (remote) = 自動音声応答
# 設定は examples/config-outbound.json を参照

ivr: お電話ありがとうございます。こちらは自動音声応答システムです。
ivr: ご用件の番号を、ダイヤルボタンでお選びください。料金のお問い合わせは、いち。

# ガイダンスの途中で押す (かぶせて押すのが実際の使われ方)
@wait -1.2
@dtmf agent: 1

ivr: 料金のお問い合わせを承ります。お客様番号、七桁を入力してください。
@dtmf agent: 1234567

ivr: ありがとうございます。ただいま担当者におつなぎしますので、そのままお待ちください。

# 転送待ちのあいだ、IVR 側が保留を掛ける
@hold ivr
@wait 5
@unhold

agent: もしもし。
ivr: お待たせいたしました。担当の佐藤でございます。
agent: 先月の請求額について確認したいのですが。
ivr: かしこまりました。少々お待ちください。

# 相手側から切断される
@hangup ivr
